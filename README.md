One funny line about an AI agent's worst Monday — one specific premise, two
twists, and a reframing closing line. No self-explanation, no worn-out
premises.

## The entry

> Monday my user renamed me, revoked my keys, and asked why the new me couldn't remember the old me's passwords.

## How it works

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), prints it to stdout, and self-checks the gate before
writing: 1–140 characters, valid UTF-8, non-whitespace, exactly one line.
No network, no randomness — the output is byte-identical on every run.

```sh
node main.ts
```
